# StarCatcher23 Portfolio & Blog

A modern, responsive personal website built with React + Vite.
This project serves as my digital home — showcasing my portfolio, sharing blog posts, highlighting my journey as a developer, and providing a clean way to connect with me.

---

## 🚀 Overview

StarCatcher23 is a multi‑page React application featuring:

* A custom Home page with a hero section, intro content, and dynamic quotes

* A Portfolio page showcasing projects with reusable card components

* A Blog page with modular blog post rendering

* A Positive Quotes API integration for uplifting daily messages

* A dedicated Contact page with LinkedIn, Gmail, and GitHub icons + addresses

* A global NavBar and Footer for consistent layout

* Clean, organized folder structure for scalability and maintainability

---

## 🧩 Features

🌟 Home Page
Custom hero section, intro content, and a dynamic Positive Quote API component.

🗂 Portfolio Page
Displays personal projects using a reusable ProjectCard component.

📝 Blog Page
Renders blog posts using a modular BlogPost component.

✨ Positive Quotes API
Fetches and displays motivational quotes to enhance user experience.

📬 Contact Page
Clean, modern contact section featuring:

LinkedIn icon + profile link

Gmail icon + email address

GitHub icon + profile link

All styled with responsive layout and accessible markup.

🎨 Custom Styling
Organized CSS structure:

global.css — base styles

responsive.css — mobile-first responsiveness

App.css — layout-level styling

index.css — root styles

🔗 Page Routing
Built with React Router:

/ — Home

/portfolio — Portfolio

/blog — Blog

/contact — Contact

/about — About Me

🔧 Component-Based Architecture
Reusable components including:

NavBar

Footer

QuoteCard

ProjectCard

BlogPost

Preloader

🛠️ Tech Stack
React 18

Vite

React Router

JavaScript (ES6+)

CSS3

Node.js + npm
