# StarCatcher23 Portfolio & Blog

A modern, responsive personal website built with **React + Vite**.  
This project serves as my digital home — showcasing my portfolio, sharing blog posts, and highlighting my journey as a developer.

---

## 🚀 Overview

StarCatcher23 is a multi‑page React application featuring:

- A custom **Home** page with a hero section and intro content
- A **Portfolio** page showcasing projects
- A **Blog** page with reusable blog post components
- A **Positive Quotes API** component for uplifting daily messages
- A global **NavBar** and **Footer** for consistent layout
- Clean, organized folder structure for scalability

---

## 📁 Project Structure

```
StarCatcher23_PortfolioBlog_React/
│── public/
│── src/
│   ├── assets/          # Images, icons, media
│   ├── components/      # NavBar, Footer, QuoteCard, BlogPost, etc.
│   ├── pages/           # Home, Portfolio, Blog
│   ├── styles/          # CSS files (global, responsive, App, index)
│   ├── App.jsx          # Main app layout + routing
│   ├── main.jsx         # React entry point
│── index.html
│── package.json
│── vite.config.js
```

---

## 🧩 Features

### 🌟 Portfolio Page

Showcases personal projects, skills, and accomplishments using custom components.

### 📝 Blog Page

Displays blog posts using a reusable `BlogPost` component.

### ✨ Positive Quotes API

A custom `QuoteCard` component fetches and displays motivational quotes.

### 🎨 Custom Styling

Organized CSS structure:

- `global.css` — base styles
- `responsive.css` — mobile-first responsiveness
- `App.css` — layout-level styling
- `index.css` — root styles

### 🔗 Page Routing

Built with **React Router**:

- `/` — Home
- `/portfolio` — Portfolio
- `/blog` — Blog

### 🔧 Component-Based Architecture

Reusable components including:

- `NavBar`
- `Footer`
- `QuoteCard`
- `BlogPost`

## ▶️ Installation & Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Your site will be available at:

```
http://localhost:5173
```
